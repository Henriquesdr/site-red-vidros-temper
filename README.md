# Red Vidros Temper — Site institucional

Site da **Red Vidros Temper**, empresa de vidros temperados e espelhos sob medida em Belo Horizonte – MG.

## Conteúdo
- Página única, responsiva (celular, tablet, desktop e telas grandes)
- Serviços com detalhes, simulador de vidro (ambiente, tipo de vidro e ferragens)
- Demonstração vidro comum × temperado
- Orçamento em 3 etapas com envio pronto para o WhatsApp
- Dúvidas frequentes, contato e localização

## Arquivos
- `index.html` — site completo (CSS e JS embutidos, logo incorporada)
- `assets/logo-red-vidros-temper.jpg` — logo original
